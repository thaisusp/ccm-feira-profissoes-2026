Os problemas científicos, não.
E se começássemos pelo problema?
Como o cérebro produz linguagem? Como podemos prever uma epidemia? Como máquinas aprendem? Como observamos o passado do Universo? Como sistemas biológicos se organizam? Como as rochas registram a história da Terra? Como mudanças ambientais reorganizam ecossistemas oceânicos? Como criar materiais que interajam com tecidos vivos?

No CM, a pergunta organiza o caminho. As áreas entram quando ajudam a responder.

Perguntas atravessam áreas

Problemas reais não respeitam departamentos.

A cada pergunta, várias linguagens científicas aparecem ao mesmo tempo.

As áreas se combinam conforme a pergunta muda.

Então, o que é o Ciências Moleculares?

Um curso da USP criado para formar estudantes capazes de atravessar fronteiras.
